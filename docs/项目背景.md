# 法律法规问答助手：项目背景与痛点

## 一、项目定位

面向普通百姓的 **法律法规智能问答助手**。用户用日常语言描述生活中遇到的问题（租房、劳动、消费、婚姻家庭、邻里纠纷、交通出行等），系统基于公开法律法规与权威解读进行检索与回答，给出 **能看懂、可对照条文、可指引下一步** 的说明。

本项目采用 RAG（检索增强生成）技术：先检索相关法条与官方材料，再据此生成回答，降低「凭空编造」风险，便于核对来源。

> **边界说明**：本助手提供普法与信息参考，**不能替代律师咨询、诉讼代理或行政机关的正式答复**。涉及重大权益、诉讼时效、证据固定等情形，应提示用户及时寻求专业法律服务。

---

## 二、项目背景

法治社会建设持续推进，公开可查的法律、行政法规、司法解释和部门规章越来越多。对专业人士而言，检索工具相对成熟；对普通百姓而言，仍普遍存在「法在网上、用不起来」的情况。

典型场景包括：

- 劳动合同被单方面解除，不知道能否主张经济补偿、去哪里投诉。
- 租房押金被扣、房东提前解约，说不清合同约定与法律规定如何对照。
- 网购退货、预付卡跑路、物业乱收费，找不到对应消费者权益或物业管理规定。
- 离婚财产、子女抚养、赡养义务等家庭问题，网上说法相互矛盾。
- 交通事故责任、工伤认定、邻里噪音等，条文分散、程序复杂。

与此同时，大模型让「用白话提问」成为可能，但若不绑定权威文本，容易出现过时法条、张冠李戴、把地方规定说成全国规定等问题。因此，需要把 **权威法律知识库 + 可追溯检索 + 面向百姓的表达** 做成一个可用的公共服务产品，而不是通用聊天机器人。

## 三、要解决的痛点

### 1. 条文难找、难读、难对号入座

法律文本按「编、章、条」组织，关键词专业（如「解除」「撤销」「不可抗力」）。百姓常用「被开除了」「押金不退」「商家不给退」来描述问题，用搜索引擎往往得到广告、自媒体或过期文章，难以定位到现行有效条文。

**本项目应对**：支持口语化提问，将生活事实映射到法律问题，检索现行有效条文并附出处。

### 2. 信息过时、来源混乱、真假难辨

修法、废止、司法解释更新频繁。自媒体、问答社区常混用旧法、地方规定和外地判例。用户难以判断「这篇说的还算不算数」。

**本项目应对**：以可更新的法规库为检索底库，回答中标明法律名称、条款号与效力状态；对已修订、已废止内容明确提示。

### 3. 咨询门槛高、成本高、不敢问

律师咨询有费用和时间成本；12348 等热线存在排队与时段限制；很多人觉得「事情不够大、不好意思问」。小额纠纷、日常维权因此被搁置，错过投诉、仲裁或诉讼时效。

**本项目应对**：提供 7×24 小时、零门槛的初步解答，帮助用户先判断「有没有法可依、大概走哪条路径」，再决定是否找专业人士。

### 4. 权利义务说不清，下一步不知道怎么走

即使找到条文，仍不清楚：自己有没有权利、对方有没有义务、证据要留什么、先去哪个部门、时限是多久。普法文章往往「讲原则、不讲路径」。

**本项目应对**：在回答中尽量包含四块信息——**法律依据、通俗解释、注意事项（时效/管辖/证据）、建议的下一步**（协商、投诉、仲裁、诉讼等，仅作指引）。

### 5. 地域与场景差异被忽略

同一问题在不同省市可能适用不同地方性法规、实施细则或部门规定。全国性问答若忽略属地，容易误导。

**本项目应对**：引导用户补充所在地区、主体身份（劳动者/消费者/承租人等）等必要事实；能区分的尽量区分全国规定与地方规定，不能确定时明确说明「需结合当地规定核实」。

### 6. 通用大模型「看起来很对、其实不可靠」

直接用通用大模型问法律问题，常见风险包括：编造不存在的条文、混淆民事与刑事、把案例当法律、忽略特别法优于一般法、对弱势群体保护条款表述不准。

**本项目应对**：生成必须 grounded 于检索结果；无足够依据时承认不确定，而不是编造；对高风险问题（刑事责任、强制措施、重大财产处分等）提高审慎提示。

## 四、目标用户与使用场景

| 用户 | 典型问题 |
|------|----------|
| 劳动者 | 加班费、辞退补偿、社保、竞业限制、工伤 |
| 租客与业主 | 押金、提前解约、房屋质量、物业费 |
| 消费者 | 退货、三包、预付卡、虚假宣传 |
| 家庭成员 | 婚姻、抚养、赡养、继承（初步了解） |
| 交通出行相关 | 责任划分原则、保险理赔相关规定的通俗说明 |
| 基层工作者、社区志愿者 | 快速查找常用条文，辅助普法宣传 |

优先覆盖 **高频、低专业门槛、与日常生活强相关** 的民事、劳动、消费者权益及常用行政法程序说明；不把「复杂商事诉讼策略」作为首期目标。

## 五、预期价值

1. **降低普法门槛**：把「查法条」变成「说人话就能问」。
2. **提高答案可核验性**：每条关键结论尽量能回到具体法律文件与条款。
3. **减少错误维权与错过时效**：尽早提示投诉渠道、仲裁/诉讼时效等关键节点。
4. **为专业服务做分流**：简单问题自助解决，复杂问题带着「问题清单和条文线索」再去找律师或法律援助。

---

## 六、建设原则（摘要）

- **权威优先**：法规原文、官方释义优于二手解读。
- **可追溯**：回答附依据，用户可点开核对。
- **通俗但不歪曲**：白话解释不得改变条文含义。
- **谦逊与安全**：不确定就说不确定；高风险场景强制免责与求助提示。
- **隐私最小化**：默认不采集与案件无关的个人身份信息。

---

## 七、成功标准（阶段性）

- 百姓用生活化语言提问，多数高频场景能返回 **对应条文 + 白话说明 + 下一步建议**。
- 抽检中，关键结论与现行有效规定一致，明显编造条文的比例趋近于零。
- 用户能在回答中看到出处，并理解「这是参考，不是判决或行政处罚决定」。
