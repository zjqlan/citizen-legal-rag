# 法律法规问答助手：流程图

当前范围：**砍掉高频问答**，只保留 RAG 离线建库 + RAG 在线检索生成。用户问题经意图分流后，法律咨询一律走混合检索，不再走 MySQL/BM25 直出答案。

---

## 1. 系统两模块关系

```mermaid
flowchart TB
    subgraph offline [RAG离线]
        D[法规原文] --> P[解析与按条分块]
        P --> E[BGE-M3 稠密+稀疏编码]
        E --> M[(Milvus 知识库)]
    end

    subgraph online [RAG在线]
        U[用户问题] --> I[意图分流]
        I -->|闲聊/情绪| C[大模型直接短回复]
        I -->|信息不足| Q[澄清追问]
        I -->|法律咨询| G[问题治理]
        G --> R[混合检索与重排]
        R --> A[大模型按检索内容作答]
        M -.-> R
    end
```

---

## 2. 离线建库流程

```mermaid
flowchart TD
    A[采集法规/司法解释等] --> B[解析结构: 编章节条款项]
    B --> C[抽取元数据: 效力/地域/条号/施行日期]
    C --> D{是否超长条?}
    D -->|否| E[一条一块]
    D -->|是| F[按款切 child, 保留 parent 整条]
    E --> G[块前缀: 法名+章节+条号]
    F --> G
    G --> H[BGE-M3]
    H --> I[稠密向量]
    H --> J[稀疏向量]
    I --> K[(写入 Milvus)]
    J --> K
    C --> L[(元数据表 / payload)]
    L --> K
```

---

## 3. 在线主流程（无 FAQ）

```mermaid
flowchart TD
    S[用户输入] --> F0[安全与空问过滤]
    F0 -->|拦截| X0[拒绝或引导]
    F0 -->|通过| I[意图分流<br/>规则 + 轻量模型, 边界再升大模型]

    I -->|闲聊 / 非法律| CHAT[大模型直接生成<br/>短回复 + 引导可问法律问题]
    I -->|需拒答| DENY[安全拒答]
    I -->|缺关键事实| ASK[澄清追问, 不检索]
    ASK --> S
    I -->|法律咨询| REW[问题治理]

    REW -->|仍缺槽且关键| ASK
    REW -->|得到 1~N 条检索 query| ENC[BGE-M3 编码 query]

    ENC --> DENSE[稠密召回 Top-K]
    ENC --> SPARSE[稀疏召回 Top-K]
    DENSE --> FILT[元数据过滤: 现行有效 / 地域]
    SPARSE --> FILT
    FILT --> RRF[RRF 融合]
    RRF --> RR[Reranker 重排]
    RR --> TOP[最终 Top-K 条文]
    TOP --> PROMPT[拼提示词: 依据+强制引用]
    PROMPT --> LLM[大模型生成白话答案]
    LLM --> OUT[返回用户]
    CHAT --> OUT
    DENY --> OUT
```

## 4. 问题治理（进入检索前）

```mermaid
flowchart TD
    Q[法律相关原问题 + 对话历史] --> A{问题形态}

    A -->|一问多问| S1[拆成子问题]
    A -->|口语不规范| S2[术语规范化]
    A -->|又长又乱| S3[归纳争议焦点]
    A -->|多轮指代| S4[改写成独立完整问句]
    A -->|情绪包裹| S5[剥离情绪, 抽出法律事实]
    A -->|对比 / 效力 / 地方| S6[改写并带上地域或时效意图]
    A -->|关键槽位缺失| S7[先追问, 暂不检索]

    S1 --> O[输出检索用 query 列表]
    S2 --> O
    S3 --> O
    S4 --> O
    S5 --> O
    S6 --> O
    S7 --> WAIT[回到用户澄清]
```

## 5. 检索子流程（双路召回）

```mermaid
flowchart LR
    Q[治理后的 query] --> M3[BGE-M3]
    M3 --> DV[稠密向量]
    M3 --> SV[稀疏向量]
    DV --> R1[Milvus 稠密 ANN]
    SV --> R2[Milvus 稀疏检索]
    R1 --> C[候选集合并]
    R2 --> C
    C --> F[效力/地域 filter]
    F --> RRF[RRF]
    RRF --> RK[BGE-Reranker]
    RK --> K[Top-K]
    K --> G[生成]
```
